# 🌶️ AURA — Rede Social +18

Aplicação front-end completa de rede social com tema escuro/vermelho, edição de perfil, chat flutuante e central de mensagens, stories interativos, reações personalizadas e painel administrativo.

## Como rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Deploy

Envie este repositório para o **GitHub** e conecte na **Vercel** ou **Netlify** (Framework: `Vite`, Build Command: `npm run build`, Output Directory: `dist`).
